# بایگانی پژوهش (Research Archive)

بایگانی کلاسی برای انتشار تکالیف، گزارش‌ها، متن‌های پژوهشی، ارائه‌ها و جزوه‌ها — فارسی و راست‌به‌چپ، با پشتیبانی از متن انگلیسی.

## نقش‌ها

- **دانشجو:** ثبت‌نام می‌کند (نام، شماره دانشجویی، دانشگاه، کلاس، استاد، زمان کلاس)، مطالبش را می‌نویسد و منتشر می‌کند، و در «میز کار» می‌بیند کدام مطلب «مشاهده شد».
- **مدیر کلاس:** اولین حساب ساخته‌شده (یا ایمیل‌های داخل `ADMIN_EMAILS`). می‌تواند مطلب را از دید عموم خارج یا دوباره منتشر کند — **اما هرگز حذف نمی‌کند**؛ کار دانشجو همیشه برای خودش محفوظ می‌ماند.
- **استاد راهنما:** بدون حساب کاربری از بخش «اطلاعات دانشجو» مطالب را می‌خواند و «مشاهده شد» ثبت می‌کند.

## دیپلوی روی Vercel

1. این مخزن را در Vercel وارد (Import) کنید.
2. در Settings → Environment Variables مقدار `DATABASE_URL` (یک PostgreSQL ابری مثل Neon) را تنظیم کنید. اختیاری: `ADMIN_EMAILS=ایمیل‌شما`.
3. Deploy کنید. جدول‌ها در اولین درخواست به‌طور خودکار ساخته می‌شوند.
4. اولین نفری که از `/signup` ثبت‌نام کند مدیر کلاس می‌شود (مگر اینکه `ADMIN_EMAILS` تنظیم شده باشد).

## اجرای محلی

```bash
npm install
cp .env.example .env   # DATABASE_URL را تنظیم کنید
npm run dev
```

حداکثر حجم هر فایل پیوست ۴ مگابایت است (محدودیت بدنهٔ درخواست در Vercel).
