# بایگانی پژوهش (Research Archive)

بایگانی کلاسی برای انتشار تکالیف، گزارش‌ها، متن‌های پژوهشی، ارائه‌ها و جزوه‌ها — فارسی و راست‌به‌چپ، با پشتیبانی از متن انگلیسی.

## نقش‌ها

- **دانشجو:** ثبت‌نام می‌کند (نام، شماره دانشجویی، دانشگاه، کلاس، استاد، زمان کلاس)، مطالبش را می‌نویسد و منتشر می‌کند، و در «میز کار» می‌بیند کدام مطلب «مشاهده شد».
- **مدیر سایت:** فقط ایمیل(های) داخل متغیر `ADMIN_EMAILS`. هیچ حساب دیگری — حتی اولین ثبت‌نام — مدیر نمی‌شود. بخش‌های مدیریت:
  - **مدیریت مطالب:** خارج کردن مطلب از دید عموم یا بازگرداندن آن — هرگز حذف نمی‌کند؛ مطلب در میز کار دانشجو می‌ماند.
  - **حساب‌ها:** دیدن همهٔ حساب‌ها و حذف یک حساب یا همهٔ حساب‌های دیگر (با تأیید). حذف حساب، مطالب همان حساب را هم پاک می‌کند.
- **استاد راهنما:** بدون حساب کاربری از بخش «اطلاعات دانشجو» مطالب را می‌خواند و «مشاهده شد» ثبت می‌کند.

## دیپلوی روی Vercel

1. این مخزن را در Vercel وارد (Import) کنید.
2. در Settings → Environment Variables تنظیم کنید:
   - `DATABASE_URL`: یک PostgreSQL ابری (مثلاً Neon).
   - `ADMIN_EMAILS`: ایمیل خودتان (برای فعال شدن بخش مدیریت لازم است).
3. Deploy کنید. جدول‌ها در اولین درخواست به‌طور خودکار ساخته می‌شوند.
4. با همان ایمیل از `/signup` ثبت‌نام کنید (یا اگر حساب دارید وارد شوید). تب‌های «مدیریت مطالب» و «حساب‌ها» فقط برای شما نمایش داده می‌شوند.

## اجرای محلی

```bash
npm install
cp .env.example .env   # DATABASE_URL و ADMIN_EMAILS را تنظیم کنید
npm run dev
```

حداکثر حجم هر فایل پیوست ۴ مگابایت است (محدودیت بدنهٔ درخواست در Vercel).
