# بایگانی پژوهش (Research Archive)

آرشیو فارسی و راست‌به‌چپ برای تکالیف، گزارش‌ها، متن‌های پژوهشی، ارائه‌ها و جزوه‌ها.

## دسترسی‌ها

- **بازدیدکنندگان:** بدون ساخت حساب، مطالب منتشرشده را می‌خوانند و می‌توانند برای هر مطلب یک‌بار دکمهٔ «من این مطلب را دیدم» را بزنند.
- **مدیر:** فقط یک ایمیل و رمز عبور که در متغیرهای محیطی تنظیم می‌شود، اجازهٔ ورود به `/login` و مدیریت محتوا را دارد. ثبت‌نام عمومی و ورود کاربران دیگر غیرفعال است.
- تعداد ثبت‌های «من دیدم» فقط در میز کار مدیر نمایش داده می‌شود. نام، ایمیل یا حسابی از بازدیدکننده جمع‌آوری نمی‌شود.

### محدودیت ثبت یک‌باره

چون بازدیدکننده حساب کاربری ندارد، شناسهٔ ناشناس در کوکی مرورگر ذخیره می‌شود و پایگاه‌داده فقط هش آن را نگه می‌دارد. بنابراین محدودیت «یک‌بار برای هر مطلب» برای هر مرورگر/دستگاه اعمال می‌شود؛ پاک‌کردن یا منقضی‌شدن کوکی، حالت ناشناس یا دستگاه دیگر می‌تواند مانند بازدیدکنندهٔ جدید شمرده شود. بدون حساب کاربری نمی‌توان هویت واقعی افراد را با قطعیت تشخیص داد.

حساب‌ها و اطلاعات قدیمی پایگاه‌داده برای حفظ نام نویسندگان مطالب قبلی باقی می‌مانند، اما امکان ورود یا ثبت‌نام آن حساب‌ها وجود ندارد.

## راه‌اندازی روی Vercel

1. مخزن را در Vercel وارد کنید و یک پایگاه‌دادهٔ PostgreSQL ابری بسازید یا وصل کنید.
2. در **Project → Settings → Environment Variables** این متغیرها را ثبت کنید:
   - `DATABASE_URL`: آدرس اتصال PostgreSQL.
   - `ADMIN_EMAIL`: ایمیل خود مدیر.
   - `ADMIN_PASSWORD`: رمز یکتای مدیر با دست‌کم ۱۶ نویسه؛ بهتر است طولانی و تصادفی باشد.
   - `ADMIN_SESSION_SECRET`: کلید محرمانهٔ نشست، حداقل ۳۲ بایت. برای ساخت مقدار تصادفی می‌توانید اجرا کنید: `openssl rand -base64 48`.
3. هر چهار متغیر را برای محیط مورد نظر (Production و در صورت نیاز Preview) تنظیم و Redeploy کنید.
4. پس از دیپلوی، از `/login` با همان ایمیل و رمز وارد شوید. میز کار مدیر در `/dashboard` است.

**رمزها و کلیدها را در GitHub، کد یا چت قرار ندهید.** فقط در Environment Variables و به‌صورت محرمانه در Vercel ثبتشان کنید. با تغییر ایمیل یا رمز، نشست‌های قبلی دیگر معتبر نخواهند بود؛ برای باطل‌کردن همهٔ نشست‌ها، `ADMIN_SESSION_SECRET` را هم عوض کنید.

جدول‌های لازم، از جمله ستون و قید یکتایی ثبت مشاهده، در اولین درخواست به‌طور خودکار ایجاد/به‌روز می‌شوند. مطالب و اطلاعات موجود حذف نمی‌شوند.

## اجرای محلی

```bash
npm ci
cp .env.example .env
# مقادیر DATABASE_URL، ADMIN_EMAIL، ADMIN_PASSWORD و ADMIN_SESSION_SECRET را در .env محلی تنظیم کنید
npm run dev
```
